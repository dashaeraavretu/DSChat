# DSChat v1 手动验收清单

本清单用于发布前的桌面版人工验收。自动化冒烟检查用 `node tests/smoke.mjs`；本清单覆盖需要真实 API、麦克风、系统权限和打包环境的项目。

## 0. 验收环境

- [ ] Windows 10/11 x64 实机或虚拟机（非仅 WSL）
- [ ] Node.js 22.12+、pnpm
- [ ] 一个有效且有余额的 DeepSeek API Key
- [ ] 可联网；如需代理，已配置系统代理
- [ ] 麦克风与扬声器可用
- [ ] 准备一个 PDF、一张图片、一个文本/代码文件、一个不支持格式的文件（如 `.exe`）
- [ ] 准备一个合法的历史 ZIP（可由应用导出的版本 3 归档）和一个损坏 ZIP

记录验收版本：`package.json` version / 安装包文件名 / 日期。

## 1. 构建与启动

- [ ] `pnpm install` 成功，无 peer dependency 阻断
- [ ] `pnpm build` 成功，`dist/index.html`、`dist/static/js/*.js`、`dist/static/css/*.css`、`dist/LICENSE` 存在
- [ ] `node tests/smoke.mjs` 全部通过
- [ ] `dist/index.html` 的 `<title>` 为 `DSChat`
- [ ] `pnpm start` 能打开桌面窗口，标题为 DSChat，无白屏
- [ ] 主进程日志显示加载 `dsc://app/index.html`（开发模式为 `http://localhost:8090`）
- [ ] `pnpm dev:desktop` 能同时启动开发服务器与 Electron，修改前端后热更新生效
- [ ] `pnpm dist:dir` 生成可运行的未打包目录，双击可启动
- [ ] `pnpm dist:win` 生成安装包；安装、启动、卸载流程正常
- [ ] 开发工具在生产包中不可用（`DevTools` 菜单/快捷键不出现）
- [ ] 关闭再启动，单实例锁生效（第二次启动聚焦已有窗口，而不是新开窗口）
- [ ] 打包版能从 `dsc://app` 启动，主进程代理能连通 API（桌面端不依赖服务端 CORS）
- [ ] 关于页「检查更新」：已配置仓库时能显示已是最新/发现新版本；未配置时提示未配置；断网/限流时显示可读错误
- [ ] 发现新版本时「打开下载页」在系统浏览器打开对应 GitHub Release；不自动下载或安装

## 2. API Key 与设置

- [ ] 首次启动无 Key 时自动打开设置，显示输入提示
- [ ] 输入无效 Key，提示无效且不保存
- [ ] 输入有效 Key，校验成功后对话框关闭，可正常发送消息
- [ ] 重启应用后 Key 仍有效（无需重新输入）
- [ ] `%APPDATA%\DSChat\secrets.json` 存在，`encrypted` 为 `true`，文件中看不到明文 Key
- [ ] 设置中更换 Key 后，新 Key 立即生效
- [ ] 设置页「清除 API Key」确认后文件被删除，应用回到未配置状态
- [ ] 渲染进程无法读取明文 Key（`window.desktop.apiKey` 不存在），桌面端 `localStorage` 中没有 Key
- [ ] `safeStorage` 不可用时 Key 仅在主进程内存，设置页显示“未加密/降级”，重启后需重输
- [ ] 删除 `secrets.json` 后重启，应用按未配置处理并提示输入 Key
- [ ] 网页版遗留 Key 迁移：在桌面版首次启动前向 `localStorage` 写入 `chat-demo:api-key`，启动后该键被清除且 Key 可用（仅开发验证）
- [ ] 设置修改语言、主题、朗读音色、位置、思考/搜索开关后重启仍保留

## 3. 多会话、标题与消息操作

- [ ] 新建对话、发送首条消息后生成会话
- [ ] 首轮回答完成后自动生成标题（服务端支持时）；不支持时标题保持“新对话”
- [ ] 手动重命名后，本轮迟到的自动标题不会覆盖手动标题
- [ ] 删除会话需确认；删除后列表中消失，重启后仍不存在
- [ ] 会话按今天/昨天/7 天/30 天分组；顺序稳定
- [ ] 编辑历史提问：生成新分支，原提问和后续回答仍可通过版本切换找回
- [ ] 版本切换可前后浏览，切回后展示对应后续分支
- [ ] 重新生成：在原提问下新增回答版本，不覆盖旧回答
- [ ] 同一会话生成中禁止编辑/重新生成/切换版本；切换到其他会话可继续新生成
- [ ] 中文输入法组合输入、Enter 发送、Shift+Enter 换行行为正常

## 4. 流式回答、停止与继续

- [ ] 回答逐字/逐段流式出现，滚动跟随；用户上滚后不被强制拉回
- [ ] 生成中显示停止按钮；点击后立即停止，保留已生成内容
- [ ] 停止后的回复显示“已停止”
- [ ] 对可继续的停止回复显示“继续”；点击后在同一消息上追加内容
- [ ] 达到输出上限（`max_tokens`）的回复可继续
- [ ] 含搜索/链接阅读工具块、被拒绝、模板提示、导入历史的回复不可继续
- [ ] 断网或服务错误时显示错误提示，可重新生成
- [ ] 无效 Key、余额不足、限流、服务繁忙分别显示对应文案与操作入口

## 5. 深度思考

- [ ] 打开 DeepThink 后发送问题，出现思考区块与思考用时
- [ ] 思考内容可展开/收起；流式更新正常
- [ ] 关闭 DeepThink 后不再出现思考区块
- [ ] 停止生成时思考区块正确收尾，不残留流式光标
- [ ] 安全拒绝时正文/思考按协议丢弃，仅保留允许展示的内容

## 6. 智能搜索、链接阅读与来源引用（API 依赖）

- [ ] 打开 Search 后提问需要实时信息的问题，出现“正在搜索”及搜索步骤
- [ ] 搜索完成后展示网页数量、来源卡片与站点信息
- [ ] 悬停正文引用角标显示来源卡片；点击角标在系统浏览器打开来源 URL
- [ ] 点击搜索步骤或结果摘要打开来源面板，链接在系统浏览器打开（不在应用内导航）
- [ ] 搜索失败/无结果时显示对应状态，不崩溃
- [ ] 关闭 Search 后普通提问不触发 web search
- [ ] 链接阅读始终启用：提问中包含 HTTP/HTTPS 链接时出现阅读步骤
- [ ] 链接读取失败时显示失败状态；无签名结果不进入后续上下文
- [ ] 多轮对话中阅读链接可复用（服务端支持签名恢复时）
- [ ] 不支持扩展能力的服务端下，相关开关不会导致应用崩溃

## 7. 附件

- [ ] 文件选择器只显示允许的扩展名；支持多选
- [ ] 拖拽文件到窗口出现拖拽遮罩，释放后加入附件
- [ ] 粘贴图片/文件到输入框可添加附件
- [ ] 图片显示缩略图；PDF/Office/文本显示文件卡片与大小
- [ ] PDF/Office/文本附件实际发送成功；如遇 `document` 块 400，记录为目标服务兼容性限制
- [ ] 选中即开始上传，显示上传中；最多 3 个并发
- [ ] 单文件超过 64 MB 被拒绝；`user_data` 类文件超过 32 MB 被拒绝
- [ ] 一次超过 50 个文件被拒绝
- [ ] 不支持格式（如 `.exe`）整批拒绝并提示支持范围
- [ ] 上传失败显示“上传失败”，可点击重试
- [ ] 服务端解析失败、配额上限分别显示对应提示
- [ ] 发送时附件与文字顺序正确；纯附件消息可发送
- [ ] 编辑/重新生成复用同一附件，不重复上传
- [ ] 点击已发送的图片/附件原件，可在受控子窗口打开本地原件（`blob:` 预览；`pnpm smoke:blob` 自动覆盖）
- [ ] 删除会话不删除服务端文件（已知行为，记录即可）
- [ ] 历史导入的文档附件无原件时仅展示，不进入请求；图片在首次使用时补传

## 8. 语音输入与朗读（ASR/TTS 依赖）

- [ ] 点击麦克风首次请求权限；允许后可录音
- [ ] 拒绝权限时提示在系统设置中开启
- [ ] 无麦克风时提示未检测到设备
- [ ] 录音中显示计时；再次点击结束并转写，文本填入输入框
- [ ] 转写中可取消；取消后不插入文本
- [ ] 录满 120 秒自动结束并转写
- [ ] 空语音提示“未检测到语音”
- [ ] 窄屏（<768px）录音时输入框首行显示实时频谱
- [ ] 回复的“朗读”按钮可播放；再次点击停止
- [ ] 切换会话、发送消息、停止生成时朗读自动停止（生成本身不因切换会话而停止）
- [ ] 切换音色（Stella/Tide）后下一次朗读生效
- [ ] 服务端不支持 TTS / 文本不可朗读时显示对应错误
- [ ] Windows 麦克风隐私设置关闭时错误可理解，不崩溃

## 11. 历史导入导出与数据管理

- [ ] 删除所有对话：确认后清空会话、附件原件、草稿；Key 与设置保留；正在生成的回答停止

## 12. 安全、打包与分发

- [ ] 安装包与 `dist/` 中不存在 API Key、`secrets.json`、`.env`
- [ ] `dist/LICENSE` 存在，安装包包含 MIT 许可证与上游署名
- [ ] 渲染进程无法访问 Node.js（`window.require`、`process` 不可用）
- [ ] HTML 响应包含严格 CSP；内联脚本不执行，渲染层不能直连 API
- [ ] 主进程代理只接受构建期 provider 白名单；自建 origin 构建后无需运行时环境变量即可工作
- [ ] 外部链接只通过系统浏览器打开；`javascript:`、`file:` 等协议被拒绝
- [ ] 应用内不加载 `<webview>`
- [ ] 生产包无法打开 DevTools
- [ ] 未签名安装包的 SmartScreen 提示已知；如签名，验证签名有效
- [ ] 安装包版本号与 `package.json` 一致；升级安装保留用户会话与 Key
- [ ] 卸载行为符合发布说明（是否保留 `%APPDATA%\DSChat`）
- [ ] 在无网络/代理不可用时给出可理解的网络错误
